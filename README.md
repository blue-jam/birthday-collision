# Birthday Pair Lab

誕生日が同じ人同士のペア数の期待値

\[
E[X] = \frac{n(n-1)}{2m}
\]

をモンテカルロ・シミュレーションで確かめるWebページです。累積平均が理論値へ収束する様子と、試行ごとのペア数の分布を表示します。

実際に観測したペア数を入力すると、シミュレーションで推定した確率質量関数を使い、確率順序による両側 p 値

\[
p = \sum_{x:\,P(X=x)\le P(X=x_{obs})} P(X=x)
\]

も計算します。有限回のシミュレーションで 0 と断定することを避けるため、表示値には add-one 補正を適用しています。

## 起動

外部ライブラリやビルドは不要です。`index.html` をブラウザで開くか、ローカルサーバーを起動してください。

```sh
python3 -m http.server 8000
```

その後、`http://localhost:8000` を開きます。
